title: BrokerApp
description: "Public catalogue and private admin for A y G Negocios Internacionales in Santa Marta. Nothing reaches the site until an administrator publishes it: the catalogue starts empty and missing contacts show an explanation, never an invented number. Quotation requests are saved before mail is attempted, so an SMTP failure never loses the request. Built on Payload CMS and local SQLite, with no public registration or customer accounts."
stack:
  - Next.js
  - Payload CMS
  - PostgreSQL
  - TypeScript
