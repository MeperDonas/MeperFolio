# omarchy-theme

Feature: adopt the omarchy.org visual theme in MeperFolio (dark, sharp-cornered,
mono-accented, terminal-flavored), reachable by reverse-engineering the live
site, plus two new content surfaces: meetup-style project cards with per-project
logos and a plugins section.

Spec source of truth for every worker: read this file up to `## Log`.

## Interface (frozen for T4)

The token *names* below are frozen so T5 can build on them. Values come from
`odd/tasks/omarchy-theme.tokens.json` (22 palettes) and `DESIGN-omarchy.md`.

`src/styles/themes.css` (new, generated from the JSON) holds one
`[data-theme="<name>"]` block per palette, each re-pointing the `--t-*` roles.
`src/styles/global.css` keeps the existing Tailwind token names so no component
has to change, and re-points them at the runtime roles:

| Existing token (unchanged name) | Aliased to |
| --- | --- |
| `--color-canvas` | `var(--t-bg)` |
| `--color-canvas-deep` (new) | `var(--t-bg-deep)` |
| `--color-surface-1` | `var(--t-surface)` |
| `--color-surface-2/3/4` | `var(--t-surface-2)` |

| `--shadow-elevation` (new) | `var(--t-elevation)` |
| `--shadow-elevation-hover` (new) | `var(--t-elevation-hover)` |

Also required:

- Radius ladder (`--radius-xs|sm|md|lg|xl` and every `rounded-*` container use)
  becomes `0px`; circles stay `rounded-full`.
- `--font-mono` becomes JetBrains Mono Variable (add
  `@fontsource-variable/jetbrains-mono`); sans stays Geist Variable.
- Theme selection: an inline `<head>` script in `src/layouts/Base.astro` reads
  `localStorage["meperfolio-theme"]`, and when absent/invalid picks a random
  palette from the dark pool or the light pool by `prefers-color-scheme`,
  persists it, and sets `document.documentElement.dataset.theme`; fallback
  `tokyo-night`.
- Switcher UI in `src/components/SiteNav.astro` listing all 22 palettes grouped
  dark/light; the choice persists and applies with no reload.
